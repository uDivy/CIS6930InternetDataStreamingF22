Steps to run the code:
1. Open the python code in the PyCharm IDE.
2. Use the following steps to build and activate the venv(virtual environment): https://www.cybrosys.com/blog/how-to-setup-virtual-environment-in-pycharm
3. Once the virtual environment is created; you can activate the virtual environment by running the following cmd on the PyCharm terminal: 
	a. You should be at the project location where the 'venv' is created.
      b. Run the following in the terminal to activate the venv: <venv\Scripts\activate>
      c. You can confirm if the following 'venv' is activated if you are able to see the 'venv' is added in front of the project path in the terminal:
           (venv) D:\.....\Project1> 
4. Once the 'venv' is activated you can install the required python dependencies using the following command: <pip install numpy>
5. Now, the environment setup is completed and you can run all the above code one by one using: <python file_name.py>
